---------
### Personal Notes
* Use `uv run` directly on a script with inline metadata; it will automatically manage the isolated environment on the fly.
* Keep `pyproject.toml` for applications and full-scale projects, but use inline script dependencies for single-file utilities or quick experiments.
* In VS Code, use `Ctrl + Shift + P` and search for "Python: Select Interpreter" to point it to the `.venv` folder generated by `uv venv` if doing traditional environment management.
